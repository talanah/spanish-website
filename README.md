# Dia de la Robinson School

Private, nicht kommerzielle Website im Stil eines Reisetagebuchs über Schulaktivitäten (Spanisch, Niveau A1-A2). Veröffentlichung über GitHub Pages.

> **Hinweis:** Dies ist ein persönliches Projekt und **keine offizielle Seite der Robinson School**. Es besteht keine Verbindung zur Schule; sie betreibt, fördert oder prüft das Projekt nicht. Der Name „Robinson School“ dient nur zur Beschreibung des Themas.
> *Esta página es un proyecto personal. No es la página oficial de la Robinson School.*

## Struktur

```
index.html        Seite (HTML, CSS, JS)
fonts/            selbst gehostete Schriften + OFL.txt
LICENSE           MIT-Lizenz (Code)
```

## Lizenzen

- **Code:** MIT-Lizenz (siehe `LICENSE`).
- **Schriften:** Cormorant Garamond und Caveat, SIL Open Font License 1.1 (siehe `fonts/`).
- **Bilder:** ausschließlich Symbolbilder aus Quellen mit freier Lizenz, die keine Namensnennung verlangen (z. B. Pixabay).

## Datenschutz

Die Seite verwendet keine Cookies, kein Tracking und keine Drittanbieter-Inhalte. Beim Aufruf verarbeitet GitHub Pages technisch bedingt Verbindungsdaten wie die IP-Adresse.
